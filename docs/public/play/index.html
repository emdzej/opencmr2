colin mcrae rally 2.0 in your browser

OpenCMR2 runs here as opencmr2.wasm on the gasm runtime: the same module as on the desktop, a port of the original game's code, reading the stages, cars, sounds and music from your own Colin McRae Rally 2.0 CD. Nothing from the game is on this site, and nothing you pick leaves your computer.

Every offline mode plays: single stages, rallies and championships, the arcade, time trials, the challenge and two players. The network game is not finished yet. See Status.

What you need

  • Colin McRae Rally 2.0 for PC (Codemasters, 2000; the program CMR2.exe version 1.11): the CD as an .iso image, its files copied off the disc, or an installed copy. See Game data.
  • A browser with WebAssembly, Web Workers, WebGL 2 and OffscreenCanvas: a recent Chrome, Edge, Firefox, or Safari 17 and later.
  • About 610 MB of browser storage to import the data (once; later visits start at once), or none to play without importing.
  • A keyboard, or a gamepad.

    Your saves

    The options, driver profiles and replays are kept in this browser.

    To move them to another browser or computer. The zip holds one file per save, as the desktop version keeps them (<data folder>/gasm/opencmr2, e.g. ~/Library/Application Support/gasm/opencmr2 on macOS), so it works both ways. Importing replaces the saves with the same names and keeps the others.

    network game

    To race others: the address of a gasm-relay and a room name, the same for every player (desktop or browser). Then choose network in the game's main menu. Leave the relay empty to play offline. See Network play.

    Controls

    The game reads the keyboard directly, with the original's default keys: the cursor keys and Enter in the menus, Esc to go back or pause. Driving: ← → steer, ↑ accelerates, ↓ brakes, Space the handbrake, ] and [ change gear (manual box), C the camera, R looks back. Game controllers work too; set them up, or change the keys, in the game's options. More in Playing in the browser.

    Holding Esc for a second stops the game. In fullscreen the browser takes Esc to leave fullscreen. Options and saves are kept in this browser.
